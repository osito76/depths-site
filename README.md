# Depths — Landing Page

Single-page GitHub Pages site for the AWS Activate application.

## Setup

1. Save the Depths key art image (the octopus splash) as `docs/depths-key-art.png`
2. Push to GitHub
3. In repo Settings → Pages → set source to `main` branch, `/docs` folder
4. Site will be live at `https://<your-username>.github.io/<repo-name>/`
